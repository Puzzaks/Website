## Generating FFMPEG


[FFMPEG](https://ffmpeg.org/) is a very powerfull instrument built for recording, converting and streaming audio and video. Using it, I was able to stream content without any input - this it why it is "Software-generated stream", there are nothing more than software. This is where I spent most time, setting up FFMPEG.



First thing worth mentioning is that FFMPEG has ability to show locally content that you are creating, using [FFPLAY](https://ffmpeg.org/ffplay.html). Also, piece of advice is to use latest WSL if you are trying this locally - it can show graphic windows on top of terminal.

In this case, I gave FFMPEG task to play Mandelbrot set, with 640x480 resolution at 60FPS, coloring it by iterations and giving also X and Y position. My prompt was:
```bash
ffplay -f lavfi -i mandelbrot=s=640x480:rate=60:outer=iteration_count:start_x=0.2550075:start_y=-0.495006
```

You can read [documentation](https://ffmpeg.org/ffmpeg-all.html#toc-mandelbrot) about it, and see how does it work here:
<details><summary>FFMPEG FFPLAY demo</summary>

[YouTube Video](https://youtube.com/watch?v=E_3IPtl3ryI)

## Streaming FFMPEG


Let's bump it up a bit. Using same FFMPEG, let's generate stream, and then send it to... Telegram.

Why Telegram? Because it's easy, fast and reliable way to livetest your entire setup online. Steps:
- Start livestream in Telegram channel
- Get credentials (server link and key)
- Set up your FFMPEG
- View your stream!

Also, don't forget to replace this part with link and this part with token from Telegram!
```bash
ffplay -f lavfi -i mandelbrot=s=640x480:rate=60:outer=iteration_count:start_x=0.2550075:start_y=-0.495006
```

## Multi-streaming


Streaming autogenerated video is cool, but guess what I find even funnier? STREAMING IT TO MULTIPLE SERVICES!

I have found that piping stream to ffplay and then splitting it in halves works pretty good, but splitting stream into tree and more sources makes it a bit unstable at times. So in example shown, stream was split into two.

I have tried (jump to the section needed) [Telegram](#telegram-streaming), [Youtube](#youtube-streaming), [Twitch](#twitch-streaming), [Facebook](#facebook-streaming) - even all of them simultaneously:

(Last 4 lines have URLs for streaming services: Twitch, Telegram, Youtube, Facebook)
```bash
ffmpeg -i backbone5.png -f lavfi -i cellauto=p=@:s=950x540:full=0:rule=18 -filter_complex overlay=x=850:y=50[out] -map [out] -map 0:a? -vcodec libx264 -pix_fmt yuv420p -preset veryfast -r 30 -g 60 -b:v "7500k" -acodec libmp3lame -ar 44100 -b:a 128k  -f mpegts - | ffmpeg -f mpegts -i - -c copy -f flv "rtmp://fra05.contribute.live-video.net/app/live_{KEY}" -c copy -f flv "rtmps://dc4-1.rtmp.t.me/s/{KEY}" -c copy -f flv "rtmps://a.rtmp.youtube.com/live2/{KEY}" -c copy -f flv "rtmps://live-api-s.facebook.com:443/rtmp/{KEY}"
```

## Twitch streaming


I have most of my experience exactly with Twitch and Telegram, I was streaming for 108 days straight, and gathered some statistics day by day (check out [spreadsheet with statistics](https://docs.google.com/spreadsheets/d/1fyD1oLGG6WDWtJLUnQ8zLQd3p_AhQxuw61aMDnqPGg8)).

Twitch is most friendly to streamer platform (no surprise here, it's the platform made solely for streaming), and it is quite easy to set up your stream.

You can read how to stream with RTMP onto Twitch [here](https://help.twitch.tv/s/article/twitch-stream-key-faq#FAQ). But that's quite an easy task, just use list of [ingest endpoints](https://stream.twitch.tv/ingests/) to determine best one for you (in my case it was Frankfurt) and just use your stream key as shown below:
```bash
rtmp://waw02.contribute.live-video.net/app/{stream_key}
```
